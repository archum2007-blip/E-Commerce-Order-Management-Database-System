# WEEK 11 – DATABASE AUTOMATION USING VIEWS AND PROCEDURES

## 1. Introduction

Database automation is used to reduce repetitive SQL operations and improve database efficiency. In this project, Views, Stored Procedures and Functions are implemented in the existing E-Commerce Database System using MySQL.

The main objective is to simplify order processing, inventory management and sales report generation.

## 2. Order Processing Automation

Order processing automation helps manage customer orders efficiently.

**Process:**
1. Accept customer ID and product details.
2. Insert a new order into the Orders table.
3. Add purchased products to the Order_Details table.
4. Calculate the total order amount.
5. Update the order status.

**Stored Procedures Used:**
- AddNewCustomerOrder
- UpdateOrderStatus
- GetCustomerPurchaseHistory

## 3. Inventory Update Automation

Inventory automation helps maintain accurate stock information.

**Process:**
1. Increase stock when new supplies arrive.
2. Reduce stock when products are purchased.
3. Identify products with low stock.
4. Display products that require restocking.

**Stored Procedures Used:**
- AddInventoryStock
- ReduceInventoryStock

## 4. Report Generation Automation

SQL queries and Views are used to generate reports quickly.

**Reports Generated:**

- Customer Order Report
- Product Sales Report
- Daily Sales Report
- Monthly Revenue Report
- Low-Stock Products Report

These reports help the company monitor sales, customer purchases and inventory availability.

## 5. SQL Functions

The following functions are created to perform automatic calculations:

1. **CalculateTotalSales** – Calculates total revenue within a given date range.
2. **CalculateCustomerSpending** – Calculates the total amount spent by a customer.
3. **CalculateProductRevenue** – Calculates the revenue generated by a product.

## 6. Testing and Results

The database objects are tested using MySQL Workbench.

- Views are tested to verify report data.
- Stored Procedures are tested using CALL statements.
- Functions are tested using SELECT statements.
- Daily and monthly sales reports are generated.
- Low-stock products are identified successfully.
